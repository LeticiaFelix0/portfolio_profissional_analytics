# Portfólio — Letícia Felix

Portfólio profissional desenvolvido em React e Vite, com projetos de análise de dados, BI, automação e processos.

## Executar localmente

```bash
npm install
npm run dev
```

## Gerar versão de produção

```bash
npm run build
```

Na Vercel, use o framework **Vite**, o comando de build `npm run build` e o diretório de saída `dist`.
